# Spam vs Ham Classification

A Machine Learning based web application that classifies messages as **Spam** or **Ham (Not Spam)** using Natural Language Processing (NLP) techniques.

## Project Overview

This project is built using **Python**, **Flask**, and **Scikit-learn**.  
The model is trained on text message data to automatically detect spam messages.

Users can enter a message through the web interface and instantly get the prediction result.


## Features

- Spam/Ham message classification
- Machine Learning based prediction
- Flask web application
- Simple and clean user interface
- NLP-based text preprocessing

##  How It Works

1. User enters a message
2. Text preprocessing is applied
3. Trained ML model predicts:
   - Spam
   - Ham
4. Result is displayed on the webpage

## Installation & Setup

### 1️⃣ Clone the Repository

```bash

```

### 2️⃣ Move to Project Folder

```bash
cd spam-vs-ham-classification
```

### 3️⃣ Install Required Libraries

```bash

```

### 4️⃣ Run the Application

```bash
python app5.py
```

### 5️⃣ Open in Browser

```bash
http://127.0.0.1:5000
```
